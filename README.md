## v1.1 使用方法与维护

- 地图：目录 → 历史地理实验室；选择七座城市或四种路线，联动查看地理、文化与神学。点击“打开在线地图”加载现代街区；支持Bing和OSM切换，另有Google独立链接。单一服务不能保证所有地区可达，本地示意图和地理底图不依赖地图服务器。
- 右下角 `⌘` 展开返回、前进、主页、顶部、底部、目录、地图、记忆卡、阅读设置；`✎` 打开个人笔记。
- 笔记：选择同一段正文文字 → 金、绿、赭、蓝色下划线；可加心得、定位原文、编辑、移除及撤销、导出和合并导入。笔记只在本机浏览器保存，三个域名之间不自动同步，请导出再导入。清理站点数据会移除本机记录。
- 编辑重点与个人笔记分开，可关闭编辑配色；阅读设置支持字号、专注模式、减少动态，尊重系统减少动态偏好。
- 内容：新增七城历史文化卡、文化机制对比表、三个核心神学问题、历史记忆路径。区分现代国界、历史区域与思想关系，不把示意连线称作实际旅程。
- 地图资源：`data/europe-countries.geojson`是Natural Earth公共领域数据的欧洲要素子集；运行 `python make_atlas.py` 生成 `dist/assets/europe.svg`。保留来源说明见 `MAP-SOURCES.md`。
- 新交互文件：`atlas.js`、`reading.js`、`notebook.js`；新样式为`upgrade.css`、`notebook.css`。`culture.html`及`history-culture.html`是新增内容的源片段；已嵌入最终HTML，后续修改须同步。
- 保留原有三个访问地址，避免书签失效；URL里的20261022/v1为项目创建标识，页面内标识和Git标签表达当前发布版本。
